# Penetration Testing & Red Teaming

Here are my walkthrough notes from retired Hack The Box machines, TryHackMe rooms, and Active Directory labs—focused on understanding offensive attack paths and how they leave footprints behind.

## Lab Setup
For offensive testing and lab environments, I run a dedicated **Kali Linux** VM equipped with the standard pentesting toolset, including:
- **Recon & Web:** Nmap, ffuf / Gobuster, Burp Suite
- **Active Directory & Lateral Movement:** BloodHound, Impacket suite, NetExec (CrackMapExec), Kerbrute, Responder
- **Exploitation & PrivEsc:** Metasploit, LinPEAS / WinPEAS, Ligolo-ng / Chisel
